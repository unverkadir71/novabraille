Kendi Sunucunuzda Barındırın

Nova Braille AGPL-3.0 lisansıyla tamamen açık kaynak. Docker ile tek komutla kendi sunucunuza kurun. Tüm özellikler sınırsız ve ücretsiz. Verilerinizin kontrolü tamamen sizde.

Tek Komutla Kurulum

SSH ile sunucunuza bağlanın ve aşağıdaki komutu çalıştırın:

curl -fsSL https://get.novabraille.com | bash

Bu komut Docker ve Docker Compose'u kontrol eder, gerekirse kurar, Nova Braille'i indirir, sizi terminal onboarding sihirbazına yönlendirir ve birkaç dakika içinde kullanıma hazır hale getirir.

Sistem Gereksinimleri

Nova Braille, Docker Compose ile 4 konteyner olarak çalışır. Aşağıdaki gereksinimler, kapsamlı bileşen analizi ve bağımsız kaynaklardan alınan referans verilere dayanmaktadır.

Minimal

Kişisel kullanım, 1-2 kullanıcı

  • 1 GB RAM
  • 1 CPU çekirdeği
  • 5 GB disk alanı
  • SQLite (varsayılan)
  • Redis olmadan çalışır
  • 64-bit Linux (amd64/arm64)

Raspberry Pi 4 (2 GB), giriş seviyesi VDS veya eski bir bilgisayarda çalışır.

Önerilen

Aile, küçük ofis, 2-10 kullanıcı

  • 2 GB RAM
  • 2 CPU çekirdeği
  • 10 GB disk alanı
  • PostgreSQL + Redis
  • Tüm servisler aktif
  • amd64 veya arm64 mimari

Çoğu kullanıcı için ideal. Tüm özellikler sorunsuz çalışır.

Profesyonel

Okul, kurum, 10-100+ kullanıcı

  • 4 GB RAM
  • 4 CPU çekirdeği
  • 20 GB disk alanı
  • PostgreSQL + Redis
  • Yedekleme aktif
  • amd64 sunucu önerilir

Eş zamanlı çoklu çeviri, yedekleme ve yüksek kullanılabilirlik için.

Bu gereksinimler nasıl hesaplandı?

Nova Braille 6 ana bileşenden oluşur. Her birinin bellek kullanımı bağımsız olarak analiz edildi:

Linux + Docker Engine
~150-300 MB. Docker'ın kendisi konteyner yönetimi için bellek kullanır. GUI olmayan bir Linux dağıtımında (Debian/Ubuntu Server) işletim sistemi ~100 MB ile çalışır.
FastAPI + Uvicorn (Python 3.13)
~100-200 MB (1 worker). Python 3.13-slim imajı, FastAPI 0.141 ve tüm bağımlılıklarla (SQLAlchemy, Pydantic, Dramatiq, structlog, httpx) yüklendiğinde ~100 MB baz bellek kullanır. Her ek worker ~80-100 MB ekler.
PostgreSQL 16
~150-500 MB. Hafif konfigürasyonda (shared_buffers=32MB, work_mem=2MB) 140 MB ile çalışabilir. Önerilen konfigürasyonda (shared_buffers=64MB) ~200-300 MB. Kurumsal kullanımda ~500 MB. Kaynak: PostgreSQL resmî dokümantasyonu, Docker Hub imaj referansları ve topluluk benchmark'ları.
Redis 7
~32-128 MB. Alpine tabanlı imaj idle'da ~32 MB tüketir. maxmem 128 MB olarak ayarlandığında kuyruk işleri için yeterlidir. Kaynak: Redis resmî dokümantasyonu, redis:7-alpine Docker imajı.
Dramatiq Worker
~50-80 MB. Python process olarak e-posta gönderimi ve arka plan işleri için çalışır. Redis bağlantısıyla birlikte bellek ayak izi.
Dosya İşleme (Pandoc + PyMuPDF)
Pandoc 3.10: DOCX/RTF/ODT/HTML dönüşümünde ~30-50 MB peak. PyMuPDF 1.28: PDF metin çıkarmada sayfa başına ~1-5 MB. 25 MB dosya limitinde peak ~100 MB.
LibreOffice Headless + Tesseract OCR
LibreOffice 25.2 (~500 MB disk): DOC formatının metne dönüşümü için headless modda çalışır, ~80-150 MB peak bellek. Tesseract OCR 5.5 (~100 MB disk, 8 dil tessdata_best): taranmış PDF'ler için 8 dilde en yüksek doğruluklu metin tanıma, sayfa başına ~100-200 MB peak.
Liblouis 3.38.0
C kütüphanesi, ihmal edilebilir (<10 MB). 141 Braille tablosu toplam 15 MB disk kullanır, dinamik olarak belleğe yüklenir. Kaynak: Liblouis GitHub deposu, proje ölçümleri.
Nginx
~20-30 MB. Statik dosya sunumu ve reverse proxy. Hafif ve minimal kaynak kullanır.

Hesaplama yöntemi: Minimal konfigürasyonda (SQLite, Redis yok, LibreOffice/Tesseract yok) toplam ~500 MB. Önerilen konfigürasyonda (PostgreSQL + Redis + LibreOffice + Tesseract) toplam ~2 GB. Her seviyeye %25-40 güvenlik payı eklendi ve en yakın tam sayıya yuvarlandı.

Veri kaynakları: PostgreSQL Docker imajı, Redis dokümantasyonu, PyMuPDF API referansı, Pandoc SSS, LibreOffice resmî dokümantasyonu, Tesseract OCR dokümantasyonu (tessdata_best), Liblouis 3.38.0 sürüm notları.

Neden Self-Hosted?

Tam Veri Kontrolü

Tüm verileriniz kendi sunucunuzda kalır. Hiçbir çeviri metni, kullanıcı bilgisi veya dosya dışarı çıkmaz. Çeviri geçmişiniz AES-256-GCM ile şifrelenir, şifreleme anahtarı yalnızca sizdedir.

Sınırsız Kullanım

Hiçbir karakter kotası, dosya limiti veya profil sınırlaması yoktur. Tüm özellikler — 8 dil, tüm dosya formatları, 3 çıktı modu, BRF/BRL üretici — sınırsız olarak kullanılabilir.

Çoklu Mimari Desteği

Docker imajımız hem amd64 (x86_64) hem de arm64 (ARM, Raspberry Pi, Apple Silicon) için üretilir. Docker otomatik olarak doğru mimariyi seçer. Debian 12+, Ubuntu 22.04+, Fedora 39+ ve ARM tabanlı sistemlerde çalışır.

Desteklenen Platformlar

Linux (amd64)

Debian 12+, Ubuntu 22.04+, Fedora 39+, RHEL 9

Docker Engine 24+ ile tam destek. Intel ve AMD işlemciler.

Linux (arm64)

Raspberry Pi OS, Ubuntu Server ARM, Debian ARM

Raspberry Pi 4/5, Apple Silicon Mac (Linux VM), ARM tabanlı sunucular.

Docker Compose

Tüm platformlarda aynı docker-compose.yml

İster amd64 ister arm64, aynı komutla kurulum. Docker otomatik mimari seçimi yapar.

Kurulum Sonrası

Discourse Tarzı Kolay Kurulum

Kurulum sonrası sizi terminal onboarding sihirbazı karşılar: domain adresi, admin e-posta ve parolası, SMTP ayarları (isteğe bağlı). Ardından tarayıcıdan admin paneline giriş yaparak site adı, logo, dil ve zaman dilimi gibi ayarları yapılandırabilirsiniz.

Web Tabanlı Admin Paneli

Discourse benzeri kapsamlı bir yönetici paneli sunulur. Kullanıcı yönetimi, e-posta ayarları, yedekleme (BorgBackup + restic), güncelleme kontrolü, sistem logları ve site ayarlarının tamamı tarayıcı üzerinden yönetilir. SSH'a bağlanmanız gerekmez.

Destek ve Topluluk

GitHub Discussions üzerinden topluluk desteği alabilir, hata bildirimi yapabilir ve özellik isteğinde bulunabilirsiniz. Self-hosted kullanıcılar için kurulum, güncelleme ve sorun giderme belgeleri docs.novabraille.com adresinde yayınlanır.
